# 03 — Ретопология: принципы и алгоритмы

**Ретопология** = построение новой, чистой сетки поверх «грязной»/плотной модели, сохраняя форму.
Зачем: анимируемость, чистый UV/бейк, контролируемый полигонаж, корректное затенение.

## Принципы хорошей ретопологии
1. **Quad-доминирование**, поток рёбер вдоль формы и линий деформации (см. 01).
2. **Edge loops** на сгибах (суставы, рот, глаза, локти) — для деформации.
3. **Плотность по важности**: больше полигонов туда, где силуэт/деформация; меньше — на плоскости.
4. **Сохранять силуэт**: упрощение не должно «съедать» очертания на фоне неба/контражуре.
5. **Острые края (hard edges)**: либо геометрией (support loops), либо фасками + бейк нормалей.
6. **Симметрия** где уместно (зеркалирование) — экономит работу и держит чистоту.

## Алгоритмы авто-упрощения/ретопо (что используем в Blender)

### 1. Decimate → Collapse  (наш `collapse`, дефолт)
- Схлопывает рёбра по метрике ошибки (quadric error). Даёт **треугольники**.
- **Сохраняет UV** и vertex-данные (важно!). Быстро.
- `ratio` 0..1 — доля оставляемых граней. `use_collapse_triangulate=True` — явная триангуляция.
- Лучшее для **LOD-цепочек**: текстуры остаются рабочими без перепекания.
- Минус: топология «уродливая» (не для анимации/сабдива).

### 2. Decimate → Planar / Dissolve  (наш `planar`)
- Растворяет рёбра между **компланарными** гранями (угол < лимита).
- Идеален для **hard-surface** (механика, архитектура): убирает лишние рёбра с плоскостей,
  не трогая силуэт. Сохраняет UV.
- `angle_limit` — порог угла (у нас ~5°). Меньше угол — осторожнее упрощает.

### 3. Decimate → Un-Subdivide
- Обратная сабдиву операция (когда модель явно перетесселирована равномерно). Узкий случай.

### 4. QuadriFlow Remesh  (наш `quad`)
- Полная **quad-ретопология** с целевым числом граней. Красивый равномерный поток.
- **Уничтожает UV** (новая сетка) → обязателен бейк (см. 05) для переноса текстур/деталей.
- Медленнее. `use_preserve_sharp`, `use_preserve_boundary` — держать острые края и границы.
- Лучшее для «чистовой» базовой сетки, не для быстрых LOD.

### 5. Voxel Remesh
- Перестраивает по вокселям → водонепроницаемая сетка, равномерные квады, но **теряет тонкие детали**
  и UV. Хорош для **3D-печати** (watertight) и как база под скульпт. Параметр — размер вокселя.

### 6. (внешнее) Instant Meshes / Quad Remesher
- Сторонние авто-ретоп-движки с лучшим quad-потоком, чем QuadriFlow. Кандидаты на интеграцию
  как альтернативный backend (Quad Remesher — платный плагин; Instant Meshes — open source CLI).

## Выбор метода (шпаргалка)
| Задача | Метод |
|---|---|
| LOD-цепочка, сохранить текстуры | **collapse** |
| Hard-surface, убрать лишнее с плоскостей | **planar** |
| Чистая база под анимацию/сабдив | **quad** (+ бейк) |
| 3D-печать (watertight) | **voxel remesh** (кандидат) |

## Препроцессинг ПЕРЕД ретопо (важно для качества) — кандидат-модуль
- Merge by distance (убрать дубли вершин) — AI-меши часто с дублями.
- Recalculate normals outside.
- Delete loose geometry (висящие вершины/рёбра).
- Fill holes / make watertight (для печати).
- Apply scale/rotation (трансформы) — иначе бейк/экспорт врут.

## Что это значит для нашего приложения
- Уже есть 3 метода. Следующее: **препроцессинг-флаг** (`--clean`) и **voxel-режим** для печати.
- Для `collapse` стоит добавить опции «беречь границы UV-швов и острые края»
  (`use_dissolve_boundaries=False`, symmetry, vertex group weighting) — чтобы LOD меньше плыли по швам.
