# 04 — UV-развёртка

UV = 2D-координаты, по которым 2D-текстура «наклеивается» на 3D-поверхность.
Без хорошего UV любая текстура/бейк выглядят растянуто, со швами и потерей разрешения.

## Ключевые понятия
- **Seam (шов)** — рёбра, по которым меш «разрезают», чтобы развернуть в плоскость.
  Прячут в малозаметные места (подмышки, внутренние края, естественные границы материалов).
- **Island (остров)** — отдельный кусок развёртки. Меньше островов = меньше швов, но больше
  искажений; больше островов = меньше искажений, но больше швов и сложнее паковать.
- **Distortion (искажение)** — растяжение/сжатие текселей. Проверяют клетчатой текстурой:
  клетки должны быть ~квадратными и одного размера везде.
- **Texel density** — px/единица поверхности; держать консистентной (см. 02).
- **UV margin / padding** — зазор между островами и до края, чтобы бейк/мипмапы не «затекали»
  на соседний остров (bleeding). Зависит от разрешения и кол-ва мип-уровней.
- **UDIM** — несколько UV-тайлов (1001, 1002…) для очень детальных ассетов. Продвинутый кейс.

## Принципы хорошего UV
1. **Минимум видимых швов**, прятать в тени/складки.
2. **Минимум искажений** на видимых участках (лицо важнее подошвы).
3. **Консистентный texel density** между островами и объектами.
4. **Плотная упаковка** (packing) — максимум полезной площади текстуры.
5. **Выравнивание** прямых элементов по осям UV (straighten) — резче текстуры, лучше упаковка.
6. Для тайлящихся материалов (кирпич, ткань) — UV может выходить за 0..1 (tiling), там switch логики.

## Авто-методы в Blender (что используем)
### Smart UV Project (наш дефолт для бейка)
- Авто-режет по углу между гранями и раскладывает. Быстро, без ручной работы.
- Параметры:
  - `angle_limit` (рад) — порог, где ставить шов по изгибу (у нас ~1.15 рад ≈ 66°).
  - `island_margin` — зазор между островами (у нас 0.02).
  - `area_weight`, `correct_aspect` — баланс по площади/пропорциям.
- Минус: швов больше и они «механические», не всегда красивые — но для авто-бейка нормалей ОК.

### Unwrap (angle-based / conformal)
- Разворачивает по заранее помеченным **швам** (seams). Даёт лучшее качество, но нужны швы
  (вручную или авто `Mark Seams from Islands` / `Seams from sharp edges`).

### Pack Islands
- Упаковывает существующие острова. Опции: rotation, margin, метод (Blender 3.6+ имеет улучшенный).

### Lightmap Pack
- Спец-режим для лайтмап (неперекрывающиеся острова) — для запекания освещения.

## Когда UV нужен, а когда нет (в нашем пайплайне)
- **collapse / planar**: оригинальные UV **сохраняются** → новый разворот НЕ нужен, текстуры рабочие.
- **quad (QuadriFlow)**: UV **уничтожены** → нужен новый разворот (мы делаем Smart UV) → затем бейк.
- **Бейк нормалей** всегда требует валидного UV у low-poly (целевого меша).

## Типичные проблемы и фиксы
- **Швы видны после бейка** → увеличить margin/padding, прятать швы, расширять «остров» бейка (dilation).
- **Мыло на части модели** → неравномерный texel density; масштабировать остров.
- **Перекрытие островов (overlap)** → бейк/текстура пачкаются; проверять и распаковывать
  (кроме намеренно зеркальных/тайлящихся).
- **Растяжение** → добавить шов, чтобы снять напряжение разворота.

## Что это значит для нашего приложения
- Сейчас для quad-режима делаем Smart UV — рабочее авто. Кандидаты-апгрейды:
  - авто-швы из острых краёв (`Seams from sharp`) + Unwrap для качества выше, чем Smart Project;
  - контроль **texel density** (задавать целевой px/cm и масштабировать острова);
  - выбор разрешения паддинга по `--bake-size` (чем больше текстура, тем меньше относительный margin).
- Для collapse-LOD UV не трогаем — это плюс к скорости и совместимости.
