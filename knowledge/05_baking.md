# 05 — Запекание (Baking): перенос деталей high → low

**Бейк** = «фотографирование» свойств high-poly и запись их в текстуры, наложенные на low-poly
по его UV. Так low-poly визуально выглядит как high-poly при малом полигонаже.

## Главные карты
- **Normal map** — направление нормалей поверхности high-poly. Создаёт иллюзию мелкого рельефа
  (поры, заклёпки, складки) на плоской геометрии. Самая важная карта для LOD.
  - **Tangent-space** (сине-фиолетовая) — стандарт для деформируемых/движущихся ассетов. Привязана
    к поверхности, работает при анимации. **Дефолт для игр.**
  - **Object/World-space** — для статичных объектов; нельзя гнуть/анимировать. Реже.
- **AO (Ambient Occlusion)** — мягкие самозатенения в щелях/впадинах. Добавляет глубину.
- **Curvature** — выпуклости/вогнутости; для процедурных материалов (грязь на гранях, потёртости).
- **Diffuse / Albedo / Color** — цвет с high-poly (если он раскрашен/текстурирован).
- **Height/Displacement** — высота; для parallax/tessellation.
- **Metallic/Roughness/ID** — PBR-каналы и маски материалов.

## Как работает «Selected to Active» (наш метод)
1. Выбрать high-poly (источник) + low-poly, low-poly сделать **активным** (цель).
2. Включить `use_selected_to_active`.
3. Для каждой точки low-poly пускается луч по нормали наружу/внутрь, ищет поверхность high-poly,
   считывает её свойство → пишет в текстуру по UV low-poly.

## Критичные параметры (и их связь с артефактами)
- **Cage / cage_extrusion / ray distance** — насколько далеко пускать лучи.
  - Мало → лучи не достают выступы high-poly → «дыры»/чёрные пятна на карте.
  - Много → лучи ловят чужую геометрию (с другой стороны) → «грязь»/искажения.
  - Идеал — **cage**-меш (раздутая копия low-poly), охватывающий весь high-poly. У нас пока
    `cage_extrusion` (упрощённый раздув) — кандидат на полноценный cage.
- **Margin / padding (dilation)** — растекание цвета за границы островов, чтобы не было швов
  на мипах. У нас margin=8 px. Масштабировать с разрешением.
- **Samples** — для AO/diffuse важно (шум), для normal обычно хватает мало. У нас 8.
- **Bake size** — разрешение карты (512/1k/2k/4k). Баланс качество/вес.
- **Anti-aliasing / supersampling** — печь в 2× и уменьшать → чище края.

## Частые артефакты и фиксы
| Симптом | Причина | Фикс |
|---|---|---|
| Чёрные точки/дыры на normal | луч не достал / cage мал | увеличить ray distance/cage |
| «Призраки» чужой геометрии | cage большой / близкие детали | уменьшить distance, использовать cage, разнести по эксплоду |
| Видимые швы | мал margin / texel mismatch | margin↑, прятать швы, выше texel density |
| Полосы/градиент на плоскости | low-poly слишком грубый под деталь | добавить геометрии или support loops |
| «Перевёрнутый» рельеф | неверный green-канал (Y) нормали | сменить Y+/Y- (DirectX vs OpenGL) под движок |
| Жёсткие грани светятся | нет согласованных нормалей/смуса | shade smooth + auto-smooth, синхронно с tangent |

## DirectX vs OpenGL normal (важно для движка!)
Зелёный канал инвертирован между конвенциями:
- **OpenGL (Y+)** — Blender, Unity (можно настроить), большинство.
- **DirectX (Y-)** — Unreal Engine, многие игровые движки.
→ Нужна **опция флипа зелёного канала** под целевой движок. Кандидат-фича (`--normal-format dx|gl`).

## Что это значит для нашего приложения
- Сейчас печём tangent-space normal (+опц. AO) методом selected-to-active, подключаем normal в материал.
- Roadmap по бейку (Этап 4 — полноценный модуль):
  1. **Cage-меш** вместо простого extrusion (точнее, меньше артефактов).
  2. **Флип Y** под DirectX/OpenGL (`--normal-format`).
  3. Доп. карты: **AO готово**, добавить **curvature, diffuse, ID**.
  4. **Supersampling** (печь 2× → downscale) для чистоты.
  5. Бейк всех LOD от одного high-poly (уже так и делаем — high всегда источник).
